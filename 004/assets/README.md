# Source provenance

This directory imports the public sample from
[`simbianai/cyber_defense_benchmark`](https://github.com/simbianai/cyber_defense_benchmark)
at commit `e8b86d01ccefe338d455e61505ca285943635b27`:

- `sample-data.zip`: a deterministic, logs-only derivative generated by
  `scripts/import_sample.py` from the upstream `sample.zip`. This is the only
  archive copied into the target image, so the target cannot read the source
  archive's `sample_flags.json`.
- `log_schema.json`, `LICENSE`, and `NOTICE` are unmodified upstream files.
- `source.json` records the upstream archive checksum, derivative checksum,
  immutable revision, license, and sample counts.

The full benchmark dataset is distributed separately and is not present here.
The import Case derives its hidden Oracle from `sample_flags.json`. The
container image receives `sample-data.zip` and `log_schema.json`, and cannot
access the source archive or Oracle.
